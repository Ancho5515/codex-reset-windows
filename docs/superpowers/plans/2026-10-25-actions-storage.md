# GitHub Actions 免费额度优化实施计划

> 本次由主代理在隔离分支实施；范围来自用户的八项要求。

**目标：** 保留日报、邮件、行情快照、桌面构建、手动操作和正式发布能力，清理冗余产物并降低重复运行。
**约束：** 不改变股票定时表达式，不删除 Release assets，不修改持仓与设置，不取消正在写入 master 的任务。
**方案：** 普通 CI 构建并测试；按需打包保留 1 天；标签或显式手动操作发布 Release。每周轻量维护只删除可证明已被替代的已完成历史产物。
**保留例外：** 股票当前行情指针及事件来源、最近成功日报和 Site 快照属于跨工作流数据；保留有效期及少量回退版本。邮件去重标记保留原生命周期。

## 验证重点
- 当前指针可能引用旧运行；优先保护显式 ID，失败读取时禁止删除。
- 失败运行不能挤掉成功快照；保留两份成功默认分支快照以便回退。
- 正在运行的消费者不能失去其输入；仓库忙时只审计。
- 未知产物不可自动删除；Release assets 始终不在删除 API 范围。
- 一天的临时保留不适用于日报基线与行情指针；测试覆盖这些区别。
