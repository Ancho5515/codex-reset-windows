# 打包与 CI 规则（2026-10-26）

- CI 仅构建和测试。手动运行 CI 也不生成安装包，已移除 package 输入和全部打包/安装包上传步骤。
- 只有用户明确要求打包时，才手动运行 release.yml，填写版本标签。推送代码、创建 PR 和推送标签都不会触发打包。
- 保留本地显式运行发布脚本的能力。GitHub Release 文件不在 Artifact 清理范围。
- CI 历史安装包全部清理，包括之前为过渡保留的最新成功包。清理必须核验来源是 ci.yml、运行已结束，并在删除后重新列举核验；运行中、来源不明或手动发布的文件不删。
- 失败测试诊断等普通临时产物仍保留 1 天。每周及默认分支 CI 结束后自动维护，忙时只审计。
